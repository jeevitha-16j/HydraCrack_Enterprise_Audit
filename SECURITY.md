# Security and Responsible Use

HydraCrack is intended for **authorized security testing, education and synthetic laboratory data**.

Do not use it against accounts, credentials, hashes, networks or systems without explicit authorization and defined scope.

The enterprise dashboard binds to `127.0.0.1` by default. Before any shared or cloud deployment, add HTTPS, strong secret management, production identity management, rate limiting, audit-log protection, encrypted storage and network controls.

The default demonstration account is for local classroom use only. Change or remove it before deployment.
